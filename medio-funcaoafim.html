Anatomia da Função

A Estrutura: f(x) = ax + b

Toda função afim é uma relação linear de causa e efeito. Para cada variação no x, temos uma variação constante no y.

  • Coeficiente Angular (a): Define a inclinação. Se a > 0, a função é crescente. Se a < 0, é decrescente. É o ritmo em que a reta sobe ou desce.
  • Coeficiente Linear (b): O ponto exato onde a reta corta o eixo Y (quando x = 0).

Atenção no Contexto

Modelagem de Problemas Reais

A Função Afim aparece muito no ENEM em problemas de finanças, transportes e física (MRU):

  1. Salário de Vendedor: Fixo + Comissão por Venda. Ex: f(x) = 1500 + 50x. (O "a" é 50, o "b" é 1500).
  2. Conta de Água/Luz: Taxa básica + Valor por consumo.
  3. Táxi/Uber: Bandeirada (fixo) + Valor por Km rodado.
⚠️ Alerta de Rasteira: Nunca confunda o coeficiente angular com o linear no texto. O que se repete/multiplica é sempre o a. O valor que você paga mesmo se x for zero é o b.
