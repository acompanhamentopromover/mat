ESTRUTURA COMPLETA DE FUNÇÕES

Módulo 1: Função Afim (A Reta)

A função do 1º grau é uma reta descrita pela fórmula f(x) = ax + b. Lemos um gráfico sempre da esquerda para a direita. Se a reta sobe, ela cresce; se desce, decresce.

f(x) = ax + b
• Coeficiente Linear (b): É a "âncora" no eixo Y (vertical). É exatamente o valor onde a reta cruza esse eixo (quando x=0).
• Coeficiente Angular (a): Dita a inclinação. Se for positivo (a > 0), a reta é crescente. Se negativo (a < 0), decrescente.
A Raiz (A Fronteira no Eixo X):
A raiz é o ponto exato onde a reta fura o eixo X (o "chão"). É onde a função muda de sinal. Para achá-la, basta igualar a equação a zero e isolar o x.
Módulo 2: A Parábola e os Extremos (Máx/Mín)

A parábola (f(x) = ax² + bx + c) não é uma curva desenhada ao acaso; ela modela limites. O sinal do coeficiente 'a' define se a função tem um "fundo do poço" ou um "topo de morro".

Cenário 1: Concavidade para Cima (a > 0)
A parábola "sorri". Ela desce, atinge um limite, e volta a subir. Esse ponto mais baixo absoluto é o Ponto de Mínimo. Em provas, isso modela "custo mínimo" ou "desperdício mínimo".
Cenário 2: Concavidade para Baixo (a < 0)
A parábola fica "triste". Ela sobe, atinge o ápice, e cai. Esse topo absoluto é o Ponto de Máximo. É o raciocínio padrão para questões de "lucro máximo" ou "altura máxima de um projétil".
Módulo 3: Encontrando as Raízes (Eixo X)

As raízes são os pontos onde a parábola "fura" o chão (eixo X). Para achá-las, igualamos ax² + bx + c = 0.

Opção 1: Equação Completa (Bhaskara)
Usamos Bhaskara quando temos a, b e c diferentes de zero.

1º Passo (O Delta):
Δ = b² - 4ac

2º Passo (A Raiz):
x =
-b ± √Δ 2a
Atenção: Se Δ < 0, a parábola "flutua" e não corta o eixo X. Não tem raízes reais!
Opção 2: Incompletas (O atalho inteligente)
Se o c = 0 (Ex: x² - 5x = 0): Coloque x em evidência.
x(x - 5) = 0 → Raízes: x = 0 ou x = 5

Se o b = 0 (Ex: 2x² - 18 = 0): Isole o x².
2x² = 18 → x² = 9 → Raízes: x = 3 e x = -3
